# 标注功能设计与验收标准 (PDF 标注 → AI 动画演示)

## 1. 设计说明

### 1.1 整体设计

- 用户在 PDF 上鼠标拖选区域 (rect), 圈定后 rect 锚定在页面内 (随滚动/缩放跟随, 不漂移)
- 圈选后弹出 AI ask 风格 popover: 提示词输入 + 交互能力动作 (本次实现「生成动画演示」)
- 「生成动画演示」: 将 当前文件名/页码/rect 位置/圈选文本 + 用户提示词, 通过 ask 请求 opencode 生成自包含 HTML5 动画演示, 保存为 `.html` 文件 (PDF 同目录, 文件名自增不覆盖)
- 生成的 html 路径记录到该标注的 interactions (demo 类型), rect 右下角显示「动画演示」按钮, 点击用编辑器打开该 html
- 标注数据持久化到 sidecar (`.{pdfBasename}.annotation`, PDF 同目录), 走 codeblitz IFileServiceClient (与 explorer/编辑器同链路)

### 1.2 设计原则

- 交互能力 = 可扩展列表 (interactions), 每种 type 有注册表 (渲染/动作); 本次先注册 demo (生成动画演示), 后续按需加新类型
- 标注数据走 codeblitz IFileServiceClient (HTTP), 不直连 service 层 FsPty (分层铁律)
- AI 生成走 AskService (独立会话, 流式回调), 不依赖 chat panel
- 圈选文本由 pdf.js textContent 按 rect 相交提取, 作为「内容」上下文传给 AI

### 1.3 核心链路

**单向传播**：
- 圈选 → 锚定 rect + 提取文本 → popover → ask (opencode 生成 HTML) → 保存 .html → sidecar 更新 → rect 按钮
- 点击「动画演示」→ 编辑器打开 html 文件
- 刷新/翻页 → sidecar 重读 → 标注 rect + 按钮恢复

**核心要点**：rect 圈定即锚定 (页面内 absolute), popover 为 AI ask 形态 (非表单), 生成结果落盘与 sidecar 原子一致

## 2. 验收标准

以下操作均在当前工作目录（“/Users/weizuxiao/Documents/鲸海拾贝”）内完成验收, 打开任意 PDF (如 数据结构（C语言版 第2版）.pdf)

### 2.1 rect 圈定与锚定

1. 鼠标在 PDF 页面上拖选区域, rect 必须保留显示且锚定在该页内
2. 保持 rect 状态下上下滚动页面, rect 必须跟随页面内容移动, 不得钉在视口 (不"跑")
3. 缩放 (放大/缩小) 后 rect 位置/比例必须正确跟随
4. Esc 或点 ✕ 后标注删除, rect 移除, sidecar 无残留
5. 误点 (<5px) 不得弹工具栏、不得残留 rect

### 2.2 标注工具栏

1. 拖选后 rect **立即标记** (自动保存标注), 弹出工具栏
2. 工具栏为**文字按钮** (不得用 icon/title): [动画演示] [代码示例] [AI讲解] [生成笔记] [生成练习] [颜色] [✕]
3. 每个工具点击即**直接动作** (无表单), 生成中按钮变「取消生成」可取消, 失败 codeblitz notification 提示
4. 颜色面板选色实时更新标注颜色

### 2.3 交互能力: AI 辅助学习工具集 (ask 驱动, 直接动作)

工具栏 = 文字按钮, 每个工具是**直接动作** (无表单), 点击即 ask opencode 生成, 支持取消/失败提示:

| 工具 | 动作 | 产物 | rect 交互按钮 |
| --- | --- | --- | --- |
| 动画演示 | ask → **可交互** HTML5 动画 (输入数据 → 动画演示算法过程) | `{pdf}-动画演示-{n}.html` | 「播放动画」打开 |
| 代码示例 | ask → 可运行代码 → 终端执行 | `{pdf}-代码示例-{n}.{py/js/sh}` | 「运行代码」终端重跑 |
| AI 讲解 | ask → 通俗讲解圈选内容 | 讲解文本 (modal 展示) | 「讲解」重看 |
| 生成笔记 | ask → 学习笔记 markdown | `{pdf}-学习笔记-{n}.md` | 「笔记」打开 |
| 生成练习 | ask → 练习题 markdown | `{pdf}-练习题-{n}.md` | 「练习」打开 |

**动画演示必须可交互** (prompt 强制要求):
- 页面提供**数据输入框** (如逗号分隔数字 / 文本), 用户可输入任意数据
- 点击「开始演示」后用动画逐步演示算法过程 (如排序: 每步比较/交换高亮)
- 控制按钮: 输入数据 / 开始 / 暂停 / 重置
- 示例: 圈选二叉树排序章节 → 生成可输入数字、逐步动画演示排序过程的 HTML

**核心链路** (所有 ask 工具一致):
```
工具栏按钮点击
  → 标注信息 prompt (文件名/页码/rect/选中文本) + 能力指令
  → ask opencode (生成中: 按钮变「取消生成」, 可取消)
  → 结果处理 (保存文件 / 显示文本)
  → sidecar interactions 记录 (type + 产物路径/文本)
  → rebuild → rect 右下角对应交互按钮
  → 失败: codeblitz notification 提示, 可重试
```

**prompt 模板** (标注信息 + 能力指令):
```
PDF 圈选内容:
- 源文件: {pdf名}
- 页码: {page}
- 圈选区域 (PDF 坐标): [x1,y1,x2,y2]
- 圈选内容: {selectedText}
{能力指令, 如: 生成 HTML5 动画 / 生成可运行代码 / 通俗讲解 / 生成学习笔记 / 生成练习题}
要求: 输出单个产物, 不要创建文件, 不要解释 (讲解类除外: 直接输出讲解内容)
```

### 2.4 交互状态机

| 状态 | 触发 | 行为 |
| --- | --- | --- |
| idle | — | 无标注交互 |
| drawing | viewer mousedown (左键, 非标注区) | 全屏 fixed 临时矩形跟随鼠标 |
| selected | mouseup (w/h ≥ 5px, 同页) | rect 即标记 (自动保存标注) + 提取选中文本 + 弹工具栏 |
| ask-running | 工具栏工具点击 | ask 请求, 按钮变「取消生成」; 失败 → notification 提示 (可重试) |
| saved | ask onComplete + sidecar 写盘 | 关 popover, rebuild 该页, rect 右下角交互按钮 |
| open-demo | 点击「播放动画」 | 编辑器打开 html 文件 |
| run-code | 点击「运行代码」 | 终端执行代码文件 |
| view-explain | 点击「讲解」 | modal 展示讲解文本 |
| open-file | 点击「笔记/练习」 | 编辑器打开对应文件 |
| deleted | 标注 ✕ 按钮 | 删 sidecar 项 (产物文件保留, 不删) |

### 2.4 交互能力验收 (各工具独立)

**动画演示**: 
1. 点击「动画演示」→ 按钮变「取消生成」, ask 发出
2. AI 返回保存为 `{pdf}-动画演示-{n}.html` (真 HTML 无 markdown 围栏), 宿主机可见
3. sidecar 标注 interactions 追加 `{type:'demo', htmlPath}` 
4. rect 右下角显示「播放动画」按钮, 点击打开 html
5. 生成中点击「取消生成」→ ask 中止, 无半成品 sidecar
6. ask 失败 → codeblitz notification 错误提示, 可重试
7. 删除标注 html 文件保留

**代码示例**:
1. 点击「代码示例」→ ask 生成可运行代码
2. 保存 `{pdf}-代码示例-{n}.{py/js/sh}` (按语言判 ext), 自动终端执行
3. sidecar interactions 追加 `{type:'code', codePath, runner}`
4. rect 右下角「运行代码」按钮 → 终端重跑

**AI 讲解**:
1. 点击「AI讲解」→ ask 生成通俗讲解文本
2. 讲解以 modal 展示 (可滚动)
3. sidecar interactions 追加 `{type:'explain', text}`
4. rect 右下角「讲解」按钮 → 重看讲解 modal

**生成笔记 / 生成练习**:
1. 点击 → ask 生成 markdown 内容
2. 保存 `{pdf}-学习笔记/练习题-{n}.md`, 编辑器打开
3. sidecar interactions 追加 `{type:'note'/'exercise', filePath}`
4. rect 右下角「笔记/练习」按钮 → 打开文件

### 2.5 回归

1. 双击已有标注弹编辑 popover, 保存覆盖不新增条目
2. 翻页/懒加载后各页标注 rect + 按钮位置正确不漂移
3. 刷新页面后标注 + 动画演示按钮恢复
4. 旧 v1 sidecar (含 comment/prompt interactions) 读盘兼容无报错, 数据不丢
