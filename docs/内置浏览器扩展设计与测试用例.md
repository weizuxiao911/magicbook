# 内置浏览器扩展设计与测试用例

> 主编辑区(main slot)的内置浏览器: URL 栏 + iframe 浏览面板 + debugger 指令 API.
> 配套: 双通道暴露 (DI token + 全局命令), 本地服务强制反代 (同源可调试).

---

## 1. 设计说明

### 1.1 整体结构

```
sumi/src/extensions/browser/
├── browser.interface.ts  IBrowserService 契约 + BrowserToken + 类型 (DOM 节点/快照)
├── browser.service.ts    BrowserServiceImpl (DI 单例) + normalizeUrl + BrowserCrossOriginError
├── BrowserView.tsx       main slot 编辑器组件 (URL 栏 + iframe)
├── module.ts             BrowserContribution (三 Domain: Resource/Editor/Command + ClientApp)
└── index.ts              桶导出

注册位置: sumi/src/config/modules.ts 添加 BuiltinBrowserModule.
入口: sumi/src/extensions/actions/ActionsView.tsx 顶栏加 🌍 globe 按钮.
```

### 1.2 设计原则

1. **同源可调试 / 跨域可浏览** — 浏览器同源策略不可绕. 但 numas 的本地服务可经 opencode `/proxy/<port>/` 反代到主进程, 注入同源 origin, 让 iframe.contentWindow 可被 debugger 访问. **任何 localhost / 127.0.0.1 / [::1] 的端口服务都强制反代**; 跨域外部网站 (如 https://example.com) 不强行反代, debugger 不可用, 只能浏览.
2. **地址栏真实 / iframe 反代 / 外部打开反代 — 三套地址分离**
   - 地址栏展示: 用户输入的原始地址 (例 `http://localhost:8000`), 不暴露反代路径, 保持用户视角一致
   - iframe 实际加载: 反代地址 `${base}/proxy/<port>/...`, 保证同源可调试
   - 在系统真实浏览器新标签打开: 反代地址 (numas 进程是主进程, 直连 localhost:8000 不可达; 反代地址由 opencode web server 接收并代理到本地服务)
3. **服务不直接依赖编辑器服务** — `BrowserServiceImpl` 不导入 `WorkbenchEditorService` (避免循环), 由模块注册的 `opener` 回调在 `ClientAppContribution.onDidStart` 阶段注入 `editorService.open(BROWSER_URI, {preview:false, focus:true})`.
4. **双通道暴露** —
   - DI token `BrowserToken` (Symbol): 内置拓展 (ActionsView 等) `useInjectable(BrowserToken as any).open()`
   - 全局命令 `numas.browser.{open, navigate, reload, openExternal, executeJs, queryDom, activeUrl}`: 任何 vscode 标准 `executeCommand` 路径 (含 vsix 拓展)
5. **debugger 受信任模式** — `executeJs` 通过 `window.eval(code)` 在目标上下文执行, 调用方必须受信 (内置代码或 vsix 拓展). 跨域抛 `BrowserCrossOriginError` 明确报错; 不静默失败也不降级到只读, 让上层明确处理 (切到只读浏览 / 拒绝 / 提示).

### 1.3 链路

```
用户点顶栏 🌍 按钮 ──→ useInjectable(BrowserToken).open()
                                  ↓
                  BrowserServiceImpl.open(undefined)
                  pendingUrl=undefined → opener() 回调
                                  ↓
                  BrowserContribution 注入的 opener
                                  ↓
                  WorkbenchEditorService.open(numas-browser://)
                                  ↓
                  editorResolverChain 匹配 BrowserView (uid='numas.browser-view')
                                  ↓
                  BrowserView 挂载 → _registerView(api) + _consumePendingUrl
                                  ↓
                  用户在 URL 栏输 localhost:8000 回车
                                  ↓
                  doNavigate('localhost:8000')
                    → normalizeUrl → { real:'http://localhost:8000',
                                       src:'http://localhost:24096/proxy/8000/',
                                       external:'http://localhost:24096/proxy/8000/' }
                    → setAddr(real)         // 地址栏
                    → setSrc(src)           // iframe.src
                                  ↓
                  iframe 加载 ${base}/proxy/8000/ → opencode 转发到 localhost:8000
                                  ↓
                  vsix 拓展调 executeCommand('numas.browser.executeJs', 'document.title')
                                  ↓
                  BrowserServiceImpl.executeJs(code)
                    → sameOriginWindow() → { win, url }
                    → win.eval(code)  // 返回值给调用方
```

### 1.4 URL 归一化规则 (normalizeUrl)

```
输入 (任意): 字符串 (无 scheme 自动补 http://)

归一化为 URL 对象:
  - 解析失败: 直接 return { real: raw, src: raw, external: raw }

判定本地服务 (isLocal):
  host ∈ { localhost, 127.0.0.1, [::1] } 且有 port

isLocal + 有 appBaseUrl():
  base = appBaseUrl()                       // localhost:24096
  rest = pathname.replace(/^\//, '') + search + hash
  proxied = ${base}/proxy/${port}/${rest}
  return { real: u.toString(), src: proxied, external: proxied }

其他 (跨域/无 port/无 base):
  return { real: u.toString(), src: u.toString(), external: u.toString() }
```

## 2. 调试 API

| 命令 (numas.browser.*) | DI 方法 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- | --- |
| `open` | `open(url?)` | url?: string | `Promise<void>` | 打开内置浏览器标签; url 缺省打开欢迎页 (空白) |
| `navigate` | `navigate(url)` | url: string | void | 当前浏览器标签导航到 url (自动归一化, 本地服务自动反代) |
| `reload` | `reload()` | - | void | 刷新当前页 |
| `openExternal` | `openExternal(url?)` | url?: string | void | 在系统真实浏览器新标签打开; 本地服务走反代地址 |
| `executeJs` | `executeJs(code)` | code: string | `Promise<unknown>` | 在 iframe 同源上下文执行 JS, 返回表达式值; 跨域抛错 |
| `queryDom` | `queryDom(selector?)` | selector?: string | `Promise<BrowserDomSnapshot>` | 返回 DOM 元素序列化 (tag/id/class/text/attributes/rect); selector 缺省返回可交互元素 |
| `activeUrl` | `activeUrl()` | - | string | 当前真实地址 (用户输入视角) |
| `activeSrc` | `activeSrc()` | - | string | 当前 iframe 加载地址 (反代视角) |

### 2.1 executeJs / queryDom 同源限制

```ts
// 内置: AI 生成 HTML (srcDoc) 或经 /proxy 反代的本地服务 → 同源, 可调试
await service.executeJs('document.title');  // → 'My App'
await service.queryDom('a.nav-link');        // → { url, title, sameOrigin:true, nodes:[...] }

// 跨域: https://example.com/ → 抛错
await service.executeJs('document.title');
// → throws BrowserCrossOriginError:
//   "内置浏览器: 目标为跨域地址 (https://example.com/), 浏览器同源策略禁止读取 DOM/执行 JS.
//    可调试场景: AI 生成 HTML (srcDoc) 或经 /proxy 反代的本地服务; 跨域合作页请用 postMessage."
```

### 2.2 postMessage 跨域桥

```ts
// 主进程: 向合作页发消息 (任何 origin 都能收到, 不会抛错)
service.postMessage({ type: 'numas-bridge', payload: { from: 'numas' } });

// 合作页 (任意 origin): window.addEventListener('message', ...) 接收
```
