# Numas 镜像构建与仓库推送备忘

> 完整链路: 编译打包 (opencode/sumi) → 构建 docker 镜像 → 冒烟验证 → 推送阿里云镜像仓库。
> 2026-09-05 服务器 (192.168.24.71) 全流程实测通过。
> 凭据不入库 (AGENTS §2.5): 各仓库登录态存服务器 `~/.docker/config.json`; 密码走交互/环境变量。

---

## 0. 核心结论 (先读)

1. **opencode 二进制构建 bun 版本必须 1.4.0** (1.4.2 产物运行时崩: fs/session 全 500 `TypeError a.name`)
2. **镜像构建只做 sumi → opencode → image 三步**, 不打包 vsix/扩展 (扩展运行时 `-v` 挂载到容器 `/root/.numas/extensions`)
3. 受限网络 (docker hub 403) 用 **legacy `docker build`** (脚本已自动: `--push` 才走 buildx)
4. 服务器上构建产物 = linux/amd64, 本机 docker 直接 `docker build` (无 buildx frontend 依赖)

---

## 1. 产物编译 (mac 构建机, bun 1.4.0)

> 详细见 `docs/Linux 编译打包部署指南.md`; 此处为镜像构建所需的最小集。

```bash
# opencode linux-x64 (服务器 x86_64 用)
cd numas/opencode/packages/opencode
mv dist/opencode-darwin-arm64 /tmp/darwin-bak      # build.ts 会 rm dist
NUMAS_TARGET=linux-x64 bun run script/build.ts --skip-embed-web-ui
mv /tmp/darwin-bak dist/opencode-darwin-arm64

# sumi UI (平台无关)
cd numas/sumi && npm run build
```

## 2. 服务器上构建 docker 镜像

### 2.1 前置 (一次性)

```bash
# 服务器: bun 1.4.0 (勿用 1.4.2!)
curl -fsSL https://bun.sh/install | bash -s "bun-v1.4.0"

# 代码 + 依赖
cd ~/numas && git pull
# (首次) scripts/docker-build.sh 会自动: sumi npm install(postinstall patch) + opencode bun install
```

### 2.2 构建 (核心命令)

```bash
cd ~/numas
mkdir -p .tmp
# --force: 强重建 sumi+opencode; --tag 自定义 (默认 numas:v<version> + latest)
nohup bash scripts/docker-build.sh --force --tag numas:latest > .tmp/docker-build.log 2>&1 &
tail -f .tmp/docker-build.log
```

脚本流程 (4 步):
```
step 1/4: 依赖安装   (sumi npm install 含 postinstall 框架 patch + opencode bun install)
step 2/4: sumi build (webpack production → sumi/dist)
step 3/4: opencode 交叉编译 (NUMAS_TARGET=linux-x64, bun 1.4.0) + smoke test --version
step 4/4: docker build 组装 (legacy builder, 无 buildx; 见 §4 坑)
```

产物复用: 已存在则跳过 (只改 UI → `--sumi`; 只改 opencode → `--opencode`; 全量 → `--force`)。

### 2.3 完成标志

```bash
docker images | grep numas
# numas  latest  024ce53a75c8  907MB
tail -3 ~/numas/.tmp/docker-build.log   # "[numas] 构建完成: ..."
```

## 3. 镜像冒烟验证 (推仓库前必做)

```bash
docker rm -f numas-test 2>/dev/null
docker run --rm -d --name numas-test -p 4096:4096 numas:latest
sleep 8

docker exec numas-test /root/.numas/exec/opencode --version   # numas-v0.1.0-<时间戳>
curl -s -o /dev/null -w "UI: %{http_code}\n" http://127.0.0.1:4096/
H="x-opencode-directory: /app"
curl -s -w " [%{http_code}]\n" "http://127.0.0.1:4096/api/fs/list?path=." -H "$H"     # 200
curl -s -w " [%{http_code}]\n" -X POST http://127.0.0.1:4096/pty -H "Content-Type: application/json" \
  -H "$H" -d '{"cwd":"/app","cols":80,"rows":24}'                                      # 200 + id

docker rm -f numas-test
```

## 4. 推送镜像仓库

### 4.1 登录

```bash
# 阿里云个人版
docker login --username weizuxiao crpi-s5r6kum9t32csfnk.cn-hangzhou.personal.cr.aliyuncs.com
# oscollege (企业版, 账号见服务器 config.json / 向用户索取密码)

```

### 4.2 tag + push (两个仓库)

```bash
V=v0.1.0
ALI=crpi-s5r6kum9t32csfnk.cn-hangzhou.personal.cr.aliyuncs.com
OSC=oscollege-registry.cn-hangzhou.cr.aliyuncs.com

# 阿里云个人版: 命名空间 = 登录用户名
docker tag numas:latest $ALI/weizuxiao/numas:$V
docker tag numas:latest $ALI/weizuxiao/numas:latest
docker push $ALI/weizuxiao/numas:$V
docker push $ALI/weizuxiao/numas:latest

# oscollege 企业版: 命名空间 oscollege (≠ 账号名, 控制台授权)
docker tag numas:latest $OSC/oscollege/numas:$V
docker tag numas:latest $OSC/oscollege/numas:latest
docker push $OSC/oscollege/numas:$V
docker push $OSC/oscollege/numas:latest
```

## 5. 坑速查 (本次实测)

| 现象 | 根因 | 处置 |
| --- | --- | --- |
| `bun: command not found` | 非交互 ssh shell PATH 无 ~/.bun/bin | docker-build.sh 已补 `export PATH="$HOME/.bun/bin:$PATH"` |
| extensions 打包失败 (vite/adm-zip not found) | 打包依赖链复杂 | 已删 vsix 打包 (只 sumi→opencode→image), 扩展挂载 |
| `docker/dockerfile:1.7 403` | 服务器拉 docker hub frontend 被限 | Dockerfile 删 `# syntax` 行; 本机构建走 legacy `docker build` |
| 镜像 UI 或 opencode 旧 | 代码更新后没强制重建 | `--force` 或 `--sumi`/`--opencode` |
| oscollege push `denied` | 命名空间用错 (cloudlab 无权限) | 正确命名空间 = `oscollege` (账号名≠命名空间) |
| 容器里 fs/pty 500 | bun 1.4.2 构建的坏产物 | bun 降到 1.4.0 重编 (smoke `--version` 时间戳核对) |

## 6. 关键文件

- 构建脚本: `scripts/docker-build.sh` (4 步: 依赖/sumi/opencode/docker)
- Dockerfile: 根目录 (无 syntax 指令, 无 vsix COPY, extensions 目录空留挂载)
- 构建日志: 服务器 `~/numas/.tmp/docker-build.log`
- 镜像内挂载点: `/root/.numas/{exec,ui,extensions}`
